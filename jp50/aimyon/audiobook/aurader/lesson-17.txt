L17｜～たり～たりする：列舉代表性動作
版本 1.0｜繁體中文＋日文｜UTF-8 純文字 TTS 版

本課目標

今天學「～たり～たりする」。

這個句型不是把一天發生的所有事情完整列完，而是挑出幾個代表性的動作，表達「做做這個、做做那個之類」。

核心形式：

動詞た形，把最後的「た」或「だ」換成「たり」或「だり」，再用「する」收尾。

見る【みる】。
見た。
見たりする。

聞く【きく】。
聞いた。
聞いたりする。

読む【よむ】。
読んだ。
読んだりする。

歌曲只作語意與聽力情境索引。本課不加入、重製或拼接完整 AIMYON 歌詞。

第一段｜先叫回 L09

L09 已經學過た形。

見る → 見た。
聞く → 聞いた。
読む → 読んだ。
話す【はなす】→ 話した。
行く【いく】→ 行った。
する → した。
来る【くる】→ 来た【きた】。

今天不是重新背一套新音便。

只要先做出た形，再加「り」。

見た → 見たり。
聞いた → 聞いたり。
読んだ → 読んだり。
行った → 行ったり。

這是最安全的處理方式。

第二段｜基本句型

休みの日は、映画を見たり、音楽を聞いたりする。
やすみの ひは、えいがを みたり、おんがくを きいたり する。
休假日會看看電影、聽聽音樂之類。

這裡列出的只是代表性活動。

它不表示休假日只做這兩件事。

所以「たり～たり」和單純的「Aして、Bする」不同。

第三段｜代表性列舉

先比較兩句。

朝ご飯を食べて、学校へ行く。
あさごはんを たべて、がっこうへ いく。
吃早餐，然後去學校。

這句容易形成動作順序。

再看：

休みの日は、本を読んだり、散歩したりする。
やすみの ひは、ほんを よんだり、さんぽしたり する。
休假日會看看書、散散步之類。

這句不是強調先讀書再散步。

它是在舉例說明「休假日通常會做哪些事」。

第四段｜た形到たり形 Retrieval

見る。

先做た形。

請暫停三秒。

答案：

見た。

再做たり形。

請暫停三秒。

答案：

見たり。

読む。

請暫停四秒。

答案：

読んだ → 読んだり。

話す。

請暫停四秒。

答案：

話した → 話したり。

行く。

請暫停四秒。

答案：

行った → 行ったり。

来る。

請暫停四秒。

答案：

来た【きた】→ 来たり【きたり】。

第五段｜句尾的する負責時態

「たり」列出活動，但整句的時態主要看最後的「する」。

週末は料理したり、映画を見たりする。
しゅうまつは りょうりしたり、えいがを みたり する。
週末會做做菜、看看電影。

昨天呢？

昨日は料理したり、映画を見たりした。
きのうは りょうりしたり、えいがを みたり した。
昨天做了做菜、看電影之類的活動。

未來也可以說：

明日は買い物したり、本を読んだりする。
あしたは かいものしたり、ほんを よんだり する。
明天會去買東西、看看書之類。

所以不要看到前面的「た」就自動判斷整句是過去。

第六段｜重要 Contrast：たり的「た」不是整句過去

「見たり」裡面雖然看得到「見た」，但「たり」已經成為列舉形式的一部分。

整句：

映画を見たりする。

仍然可以描述現在習慣或未來安排。

回想題。

週末は音楽を聞いたりする。

這句一定是過去嗎？

請暫停五秒。

答案：

不一定。

整句時態要看句尾「する」。

第七段｜兩項最容易聽懂，但不是只能兩項

教科書常用：

Aたり、Bたりする。

因為兩項最容易看出「列舉」。

但實際上可以列更多項，也可以只出現一個「たり」來暗示「像這樣的事情等等」。

本課輸出練習先以兩項為主，讓結構穩定。

第八段｜同一主題下的活動

自然的列舉通常共享一個主題或情境。

例如：

夜は音楽を聞いたり、本を読んだりする。
よるは おんがくを きいたり、ほんを よんだり する。
晚上會聽聽音樂、看看書。

兩個活動都屬於「晚上會做的事」。

聽到「たり」時，不只追回動詞，也要問：

這幾個動作共同在描述什麼情境？

第九段｜Contrast：て形與たり

て形：

ドアを開けて、部屋に入る。
ドアを あけて、へやに はいる。
打開門，進房間。

這裡有明顯先後關係。

たり：

部屋で音楽を聞いたり、本を読んだりする。
へやで おんがくを きいたり、ほんを よんだり する。
在房間會聽音樂、看書之類。

這裡重點是代表性活動，不是順序。

第十段｜錯誤修正

錯誤一：

見る → 見るたり。

請暫停五秒。

答案：

先做た形。

見る → 見た → 見たり。

錯誤二：

読む → 読みたり。

請暫停五秒。

答案：

這不是ます語幹句型。

読む → 読んだ → 読んだり。

錯誤三：

行く → 行きたり。

請暫停五秒。

答案：

回想 L09 的例外。

行く → 行った → 行ったり。

錯誤四：

昨日は映画を見たり、本を読んだりする。

如果明確要說昨天做過的活動，句尾時態不一致。

請暫停五秒。

答案：

昨日は映画を見たり、本を読んだりした。

第十一段｜する本身也能進入列舉

勉強する【べんきょうする】。

た形：

勉強した。

たり形：

勉強したり。

原創例句：

家で勉強したり、音楽を聞いたりする。
いえで べんきょうしたり、おんがくを きいたり する。
在家會讀讀書、聽聽音樂之類。

第十二段｜原創短篇

休みの日は、朝ゆっくり起きる。
昼は本を読んだり、近くを歩いたりする。
夜は映画を見たり、友達と話したりする。

讀音提示：

休み【やすみ】。
朝【あさ】。
起きる【おきる】。
昼【ひる】。
本【ほん】。
読む【よむ】。
近く【ちかく】。
歩く【あるく】。
夜【よる】。
映画【えいが】。
友達【ともだち】。
話す【はなす】。

語意摘要：

說話者先交代休假日的大方向，再用兩組「たり」挑出白天與晚上的代表性活動。

這不是精確行程表。
它是在建立生活場景。

第十三段｜AIMYON 聽力情境索引

歌曲裡聽到「たり」時，做四步。

第一步：

追回原形。

見たり → 見る。
聞いたり → 聞く。
読んだり → 読む。

第二步：

找同一組還有哪些「たり」。

第三步：

判斷這些事件是在列舉哪一類代表性場景。

第四步：

看最後的述語決定整句時間與態度。

不要因為「たり」裡有た形的聲音，就誤判整段一定在回憶過去。

第十四段｜跨課連結

L08 的て形：

事件連接，常能表現順序或方法。

L09 的た形：

完成、過去，是今天形成たり的基礎。

L16 的ながら：

同一主體同時做兩個動作，句尾通常是主要動作。

L17 的たり：

挑出代表性動作列舉，不強調完整清單，也不一定表示先後。

Contrast：

音楽を聞きながら歩く。
一邊聽音樂一邊走路。

音楽を聞いたり、歩いたりする。
會聽聽音樂、走走路之類。

前者是同時。
後者是列舉。

第十五段｜生成任務

請描述自己的休假日。

至少使用兩個不同動詞。

第一步：

想兩個代表性活動。

第二步：

各自做成た形。

第三步：

把た或だ接成たり或だり。

第四步：

最後加する。

請暫停二十五秒。

原創示例：

休みの日は、写真を撮ったり、カフェで本を読んだりする。
やすみの ひは、しゃしんを とったり、カフェで ほんを よんだり する。
休假日會拍拍照、在咖啡店看看書之類。

請換成自己的活動。

第十六段｜時態生成

把剛才的句子改成「昨天」。

句尾的する要怎麼變？

請暫停五秒。

答案：

した。

例如：

昨日は写真を撮ったり、本を読んだりした。
きのうは しゃしんを とったり、ほんを よんだり した。

第十七段｜Rapid Retrieval

聞く。

請暫停三秒。

答案：

聞いた → 聞いたり。

遊ぶ【あそぶ】。

請暫停三秒。

答案：

遊んだ → 遊んだり。

書く【かく】。

請暫停三秒。

答案：

書いた → 書いたり。

待つ【まつ】。

請暫停三秒。

答案：

待った → 待ったり。

する。

請暫停三秒。

答案：

した → したり。

来る。

請暫停三秒。

答案：

来た → 来たり。

第十八段｜Exit Retrieval

「看看電影、聽聽音樂之類」。

請暫停六秒。

答案：

映画を見たり、音楽を聞いたりする。
えいがを みたり、おんがくを きいたり する。

「昨天看看書、散散步之類」。

請暫停六秒。

答案：

昨日は本を読んだり、散歩したりした。
きのうは ほんを よんだり、さんぽしたり した。

たり前面的形式從哪裡來？

請暫停四秒。

答案：

從た形來。

整句時態主要看哪裡？

請暫停四秒。

答案：

看最後的述語，典型句型中是する、した等。

「ながら」和「たり」的核心差異？

請暫停六秒。

答案：

ながら表示同一主體同時進行動作。
たり表示代表性列舉，不要求同時，也不強調完整清單。

L17 課末速查

基本公式：

動詞た形＋り。

見た → 見たり。
聞いた → 聞いたり。
読んだ → 読んだり。
話した → 話したり。
行った → 行ったり。
した → したり。
来た → 来たり。

典型句型：

Aたり、Bたりする。

意思：

做做 A、做做 B 之類。
列出代表性活動，不表示完整清單。

時態：

Aたり、Bたりする。
現在習慣或依語境表示未來。

Aたり、Bたりした。
過去。

重要警告：

たり中的「た／だ」來自た形，但不能單靠它判斷整句是過去。

Contrast：

て形：
常連接事件、順序或方法。

ながら：
同一主體同時進行兩個動作。

たり：
代表性列舉。

歌曲聽辨：

追回原形。
找同組たり。
判斷共同場景。
最後看述語決定時間與敘事功能。
