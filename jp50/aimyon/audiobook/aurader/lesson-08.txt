L08｜て形：把動作接起來的核心接口
版本 1.0｜繁體中文＋日文｜UTF-8 純文字 TTS 版

【本課目標】
今天接續 L06 的動詞分類與 L07 的變形判斷，學會動詞的「て形」。
你會掌握五段動詞的五組音便、一段動詞的規則、不規則動詞，以及必記例外「行く → 行って」。
學完後，不只要會填答案，還要能在句子裡判斷：て形是在連接動作、提出請求，還是準備接到其他文法。

提醒：て形本身通常不表示時態。整句是現在、未來或過去，常由最後的述語決定。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第一段｜先叫回 L06
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

動詞先分四路：
五段動詞。
一段動詞。
する。
来る【くる】。

一段動詞多半去掉「る」再接續。
五段動詞不能只去掉最後一個假名；要看辭書形的尾音分組。

回想題。
見る【みる】是哪一類？
請停五秒。
答案：一段動詞。

聞く【きく】是哪一類？
請停五秒。
答案：五段動詞。

帰る【かえる】雖然以「る」結尾，是哪一類？
請停五秒。
答案：五段動詞。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第二段｜五段動詞的五組音便
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

第一組：う、つ、る → って。

買う【かう】→ 買って【かって】。
待つ【まつ】→ 待って【まって】。
帰る【かえる】→ 帰って【かえって】。

記憶口訣：う、つ、る，變成小促音「って」。

第二組：む、ぶ、ぬ → んで。

読む【よむ】→ 読んで【よんで】。
遊ぶ【あそぶ】→ 遊んで【あそんで】。
死ぬ【しぬ】→ 死んで【しんで】。

記憶口訣：む、ぶ、ぬ，鼻音收進「んで」。

第三組：く → いて。

書く【かく】→ 書いて【かいて】。
聞く【きく】→ 聞いて【きいて】。
歩く【あるく】→ 歩いて【あるいて】。

但是「行く【いく】」是高頻例外。
行く → 行って【いって】。
不是「行いて」。

第四組：ぐ → いで。

泳ぐ【およぐ】→ 泳いで【およいで】。
急ぐ【いそぐ】→ 急いで【いそいで】。

請注意清音與濁音：
く接「いて」。
ぐ接「いで」。

第五組：す → して。

話す【はなす】→ 話して【はなして】。
探す【さがす】→ 探して【さがして】。
渡す【わたす】→ 渡して【わたして】。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第三段｜一段與不規則動詞
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

一段動詞：去掉「る」，加「て」。

見る → 見て【みて】。
食べる【たべる】→ 食べて【たべて】。
起きる【おきる】→ 起きて【おきて】。
伝える【つたえる】→ 伝えて【つたえて】。

不規則動詞：

する → して。
勉強する【べんきょうする】→ 勉強して【べんきょうして】。

来る【くる】→ 来て【きて】。
「来て」的讀音是「きて」，不要照字面讀成「くて」。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第四段｜て形不是時態
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

例句一。
朝ご飯を食べて、学校へ行く。
あさごはんを たべて、がっこうへ いく。
吃完早餐，去學校。

例句二。
朝ご飯を食べて、学校へ行った。
あさごはんを たべて、がっこうへ いった。
吃完早餐，去了學校。

前半兩句都是「食べて」。
第一句最後是「行く」，整體是非過去。
第二句最後是「行った」，整體是過去。

所以聽歌或讀句子時，不要看到「て」就急著判斷時間。
先把句子聽到最後，再確認最後的述語。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第五段｜把動作接成畫面
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

て形可以把動作依序接起來。

窓を開けて、風を感じる。
まどを あけて、かぜを かんじる。
打開窗戶，感受風。

音楽を聴いて、駅まで歩く。
おんがくを きいて、えきまで あるく。
聽著音樂，走到車站。

手紙を書いて、机の上に置いた。
てがみを かいて、つくえの うえに おいた。
寫了信，放在桌上。

同一個「て形」在中文裡不一定都翻成「然後」。
它也可能呈現伴隨狀態、原因，或接到另一個文法。
本課先穩定辨認形式；之後再學各種功能。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第六段｜高頻接口預告
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

聞いてください。
請聽。

聞いている。
正在聽；或處於持續聽的狀態。

聞いてみる。
試著聽聽看。

聞いてほしい。
希望對方聽。

聞いていく。
從現在往後持續聽下去。

聞いてくる。
一路發展到現在，或從外面完成「聽」再回來；具體意思要看語境。

這些形式共同的入口都是：
聞く → 聞いて。

所以「て形」不是一個孤立章節。它是後面多個 N4 到 N3 常用結構的插座。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第七段｜AIMYON 歌曲理解連結
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

以下是教學聽法，不是歌詞引用。

一，歌曲「君はロックを聴かない」。
先從歌名叫回動詞「聴く」。
把它變成て形：聴いて。
接著預測後續可能出現的功能，例如請求、期待或持續狀態。
再回到歌曲教材，判斷實際句子使用的是哪一種形式，不要憑想像補歌詞。

二，歌曲「ハルノヒ」的未來與時間方向任務。
之後的「ていく／てくる」都需要て形。
現在先把「行く → 行って」與一般「く → いて」的差別記穩，未來才不會把兩套規則混在一起。

三，歌曲場景的連續畫面。
聽到多個動作時，先找句尾，再往前辨認て形串起的動作。
順序是：聽到 → 辨認尾音 → 追回辭書形 → 判斷連接功能 → 再聽一次。
這比逐字翻譯更容易保留歌曲的敘事流動。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第八段｜Contrast：最容易混淆的地方
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

一，帰る與食べる。

帰る是五段。
帰る → 帰って。

食べる是一段。
食べる → 食べて。

不能看到「る」就一律去る加て。

二，聞く與行く。

聞く → 聞いて。
行く → 行って。

兩個都以「く」結尾，但行く是高頻例外。

三，く與ぐ。

書く → 書いて。
泳ぐ → 泳いで。

請把「いて」與「いで」的清濁一起記。

四，来る的讀音。

来る【くる】→ 来て【きて】。
字形保留「来」，讀音會變化。

第九段｜主動回想
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

請先回答，再聽答案。

題目一。
待つ的て形。
請停五秒。
答案：待って。

題目二。
読む的て形。
請停五秒。
答案：読んで。

題目三。
聞く的て形。
請停五秒。
答案：聞いて。

題目四。
泳ぐ的て形。
請停五秒。
答案：泳いで。

題目五。
話す的て形。
請停五秒。
答案：話して。

題目六。
見る的て形。
請停五秒。
答案：見て。

題目七。
行く的て形。
請停五秒。
答案：行って。

題目八。
来る的て形與讀音。
請停五秒。
答案：来て，讀作「きて」。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十段｜錯誤修正
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

錯誤一：本を読いてください。
「読む」以「む」結尾，應變成「んで」。
正確：本を読んでください。
ほんを よんで ください。
請讀這本書。

錯誤二：明日、東京へ行いて、友達に会う。
行く是例外。
正確：明日、東京へ行って、友達に会う。
あした、とうきょうへ いって、ともだちに あう。
明天去東京，和朋友見面。

錯誤三：音楽を聞くて、歩く。
五段「く」不能直接加て。
正確：音楽を聞いて、歩く。
おんがくを きいて、あるく。
聽著音樂走路。

錯誤四：七時に起って、朝ご飯を食べる。
「起きる」是一段動詞。
正確：七時に起きて、朝ご飯を食べる。
しちじに おきて、あさごはんを たべる。
七點起床，吃早餐。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十一段｜生成任務
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

任務一。
用兩個動作描述出門前的流程。
請至少使用一個て形。
參考答案：
顔を洗って、服を着る。
かおを あらって、ふくを きる。
洗臉，穿衣服。

任務二。
把下列兩句接起來。
音楽を聴く。駅まで歩く。
請停八秒。
參考答案：
音楽を聴いて、駅まで歩く。

任務三。
自己選一個 AIMYON 歌曲場景，不引用歌詞，用兩個原創動作描述你腦中的畫面。
例如：
空を見て、ゆっくり歩く。
そらを みて、ゆっくり あるく。
看著天空，慢慢走。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
課末速查
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

五段：
う、つ、る → って。
む、ぶ、ぬ → んで。
く → いて。
ぐ → いで。
す → して。

例外：
行く → 行って。

一段：
去る，加て。
見る → 見て。

不規則：
する → して。
来る → 来て【きて】。

理解句子時：
先聽到最後。
用最後的述語判斷時態。
再判斷前面的て形是連接動作，還是接到其他文法。

最後一次回想。
聞く、行く、帰る、見る。
請依序說出て形。
請停八秒。
答案：
聞いて、行って、帰って、見て。
