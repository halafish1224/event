L15｜～すぎる：超過適當程度
版本 1.0｜繁體中文＋日文｜UTF-8 純文字 TTS 版

本課目標

Unit 3 已經建立い形容詞、ナ形容詞、否定與過去，以及狀態改變。今天加入「～すぎる」，表達某個程度或動作超過說話者認為合適的範圍。

今天掌握四條主線：

い形容詞：去掉い，加すぎる。
強い → 強すぎる。

特殊詞いい：回到よい的基底。
いい → よすぎる。

ナ形容詞：直接加すぎる，不加な。
静か → 静かすぎる。

動詞：使用ます形去掉ます的語幹，再加すぎる。
見る → 見すぎる。

歌曲只作語意與聽力情境索引。本課不收錄、拼接或重組完整 AIMYON 歌詞。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第一段｜～すぎる的核心語意
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

「～すぎる」表示超過某個基準，可以翻成「太……」、「過於……」或「……過頭」。

この音は大きすぎる。這個聲音太大。
この部屋は静かすぎる。這個房間太安靜。
昨日は食べすぎた。昨天吃太多了。

重點不只是程度高，而是說話者覺得超出當下需要、期待或承受範圍。

比較：

この音はとても大きい。這個聲音非常大。
この音は大きすぎる。這個聲音太大了。

「とても大きい」只提高程度。
「大きすぎる」通常加入超過標準的判斷。

但是口語中的「よすぎる」、「好きすぎる」有時用來表達強烈讚嘆或情感，不一定真的在抱怨。最後仍要看上下文與語氣。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第二段｜い形容詞：去い加すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

規則：去掉最後的「い」，加「すぎる」。

強い【つよい】→ 強すぎる。太強。
長い【ながい】→ 長すぎる。太長。
暑い【あつい】→ 暑すぎる。天氣太熱。
寒い【さむい】→ 寒すぎる。太冷。
高い【たかい】→ 高すぎる。太高；太貴。
優しい【やさしい】→ 優しすぎる。太溫柔；過於和善。

原創例句。

この風は強すぎる。這陣風太強。
この話は長すぎる。這段話太長。
今日は暑すぎる。今天太熱。
その店は高すぎる。那間店太貴。

不要保留最後的い。

錯誤：強いすぎる。
正確：強すぎる。

回想題。

「太冷」怎麼說？
請暫停五秒。
答案：寒すぎる。さむすぎる。

「太貴」怎麼說？
請暫停五秒。
答案：高すぎる。たかすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第三段｜特殊詞：いい → よすぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

「いい」活用時回到「よい」這個基底。接「すぎる」時，也使用「よ」。

いい → よすぎる。太好；好得不得了。

不是「いいすぎる」。

請注意，「言いすぎる【いいすぎる】」是另一個詞，來自動詞「言う」，意思是說太多、說過頭。它的讀音碰巧和錯誤想像很接近，但結構完全不同。

形容詞：
よすぎる。太好。

動詞：
言いすぎる。說太多。

原創例句。

この景色はよすぎる。這個景色好得不得了。
条件がよすぎて、少し不安だ。條件好得讓人有點不安。
私は言いすぎた。我說過頭了。

回想題。

「太好」怎麼說？
請暫停五秒。
答案：よすぎる。

「說太多」怎麼說？
請暫停五秒。
答案：言いすぎる。いいすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第四段｜ナ形容詞：直接加すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

ナ形容詞不用「な」，直接加「すぎる」。

静か【しずか】→ 静かすぎる。太安靜。
きれい → きれいすぎる。太漂亮；太乾淨。
簡単【かんたん】→ 簡単すぎる。太簡單。
元気【げんき】→ 元気すぎる。精神太好；過於有活力。
好き【すき】→ 好きすぎる。太喜歡；喜歡得不得了。

原創例句。

この町は静かすぎる。這座城鎮太安靜。
この問題は簡単すぎる。這題太簡單。
この部屋はきれいすぎる。這個房間乾淨得不可思議。
私はこの曲が好きすぎる。我太喜歡這首曲子了。

口語中的「好きすぎる」經常是強烈情感表達。它可以帶甜蜜、困擾、誇張或自嘲，不能只翻成負面的「喜歡過頭」。

錯誤：静かなすぎる。
正確：静かすぎる。

回想題。

「太安靜」怎麼說？
請暫停五秒。
答案：静かすぎる。

「太喜歡」怎麼說？
請暫停五秒。
答案：好きすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第五段｜動詞：ます語幹加すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

動詞使用ます形去掉「ます」後的語幹，再加「すぎる」。

見る → 見ます → 見すぎる。看太多。
聞く → 聞きます → 聞きすぎる。聽太多；問太多。
食べる → 食べます → 食べすぎる。吃太多。
飲む → 飲みます → 飲みすぎる。喝太多。
考える → 考えます → 考えすぎる。想太多。
話す → 話します → 話しすぎる。說太多。
する → します → しすぎる。做太多。
来る【くる】→ 来ます【きます】→ 来すぎる【きすぎる】。來得太多；來得太頻繁。

原創例句。

昨日、動画を見すぎた。昨天看太多影片。
音楽を聞きすぎて、寝る時間が遅くなった。聽太多音樂，結果睡晚了。
心配して、考えすぎた。因為擔心而想太多。
週末に寝すぎた。週末睡太久了。

「見る」是一段動詞，去掉ます後留下「見」。
所以不是「見るすぎる」，而是「見すぎる」。

回想題。

「看太多」怎麼說？
請暫停五秒。
答案：見すぎる。みすぎる。

「想太多」怎麼說？
請暫停五秒。
答案：考えすぎる。かんがえすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第六段｜～すぎる本身像一段動詞
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

接上「すぎる」之後，整體可以像一段動詞一樣活用。

強すぎる。太強。
強すぎない。不算太強；沒有過強。
強すぎた。當時太強。
強すぎなかった。當時沒有太強。
強すぎて。因為太強；太強而……

見すぎる。看太多。
見すぎない。不要看太多；不會看過量。
見すぎた。看太多了。
見すぎなかった。當時沒有看太多。
見すぎて。因為看太多；看太多而……

原創例句。

この光は強すぎて、目が疲れる。這道光太強，眼睛會累。
昨日は考えすぎて、眠れなかった。昨天想太多，睡不著。
その説明は長すぎなかった。那段說明沒有太長。

聽歌時若聽到「すぎた」，先追回「すぎる」，再追回前面的基本詞。兩層都追回來，才能知道是什麼超過了標準。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第七段｜Contrast：とても與～すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

とても：非常、很。主要提高程度。
～すぎる：太、過於。加入超出標準的判斷。

今日はとても暑い。今天非常熱。
今日は暑すぎる。今天熱過頭了。

この歌はとても長い。這首歌很長。
この歌は長すぎる。這首歌太長了。

彼はとても優しい。他非常溫柔。
彼は優しすぎる。他過於溫柔。

最後一句可能是在稱讚，也可能暗示他容易勉強自己。要靠前後文判斷。

回想題。

只是想說「非常安靜」，沒有批評超過標準。
請暫停五秒。
答案：とても静か。

想說「安靜得有點不自然」。
請暫停五秒。
答案：静かすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第八段｜Contrast：すごく與～すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

すごく：非常、超級。口語中常用來強調程度。
～すぎる：形式上表示超過某個基準。

すごく好きだ。非常喜歡。
好きすぎる。太喜歡；喜歡得不得了。

すごくいい。非常好。
よすぎる。好得過頭；好得不可思議。

日常口語會把「～すぎる」用成誇張讚嘆，因此不一定帶實際問題。判讀時要問：

說話者是在抱怨負擔？
是在驚訝？
是在熱烈稱讚？
還是在用誇張語氣表達感情？

文法提供「超過標準」的骨架；情境決定這個超過是困擾、驚喜還是玩笑。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第九段｜結果接續：～すぎて
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

「～すぎて」常把過度狀態連到後面的結果。

暑すぎて、眠れない。太熱，睡不著。
静かすぎて、少し怖い。太安靜，有點可怕。
考えすぎて、分からなくなった。想太多，反而搞不懂了。
好きすぎて、うまく話せない。太喜歡，反而沒辦法好好說話。

這些例句的後半部都是原創結果。實際歌曲裡如果句子停在「～すぎて」，後面的原因結果也可能延到下一句；不要過早在行末切斷語意。

「て」在這裡不是新的詞尾規則，而是「すぎる」的て形：

すぎる → すぎて。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十段｜並非所有「多」都用すぎる
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

量很多，可以用「多い【おおい】」。

人が多い。人很多。
人が多すぎる。人太多。

第一句只描述數量多。
第二句表示多到超過說話者認為合適的範圍。

再比較：

質問が多い。問題很多。
質問が多すぎる。問題太多了。

聽到「很多」時，不要自動翻成「すぎる」。先確認原句是在客觀描述，還是加入過量判斷。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十一段｜錯誤修正
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

錯誤一：強いすぎる。
請暫停六秒。
答案：い形容詞去掉最後的い。正確是強すぎる。

錯誤二：いいすぎる，想表達「太好」。
請暫停六秒。
答案：いい回到よい的基底。正確是よすぎる。「言いすぎる」則是動詞「言う」的說太多。

錯誤三：静かなすぎる。
請暫停六秒。
答案：ナ形容詞直接接すぎる，不加な。正確是静かすぎる。

錯誤四：見るすぎる。
請暫停六秒。
答案：動詞用ます語幹。見る→見ます→見すぎる。

錯誤五：今日はとても暑すぎる。
請暫停六秒。
答案：日常口語偶爾會聽見，但基礎表達通常避免程度標記重疊。只想說非常熱，用とても暑い；想說熱過頭，用暑すぎる。

錯誤六：すぎる永遠是負面。
請暫停六秒。
答案：錯。核心是超過標準，但口語也可表達驚喜、讚嘆或誇張情感，例如よすぎる、好きすぎる。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十二段｜AIMYON 聽力情境索引
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

聽 AIMYON 時遇到「～すぎる」，可以用五步判讀。

第一步，抓住「すぎ」。
它後面可能接「る、ない、た、て」等活用。

第二步，追回前面的基本詞。
強すぎる追回強い。
静かすぎる追回静か。
見すぎる追回見る。
よすぎる追回いい。

第三步，判斷詞類。
い形容詞、ナ形容詞與動詞，接法不同。接法本身也是追回原形的線索。

第四步，找出被超過的隱含標準。
太長、太安靜、太喜歡，是超過誰的期待？是說話者的負擔、社會常態，還是誇張讚嘆？

第五步，放回敘事結果。
如果後面接「て」，找它導向的感受或事件。過度狀態常是後續轉折的原因。

這是教學判讀流程。若歌曲沒有明說標準或原因，不要把推論冒充成歌詞文字。

＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝
第十三段｜跨課整合
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

L11：
辨認い形容詞與「いい」的特殊基底。

L12：
建立強い、強くない、強かった、強くなかった。

L13：
建立強くなる與よくなる，描述狀態變化。

L14：
建立静かだ、静かな、静かじゃない、静かになる。

L15：
建立強すぎる、よすぎる、静かすぎる、見すぎる。

原創短篇。

昨日は暑すぎた。
夜になっても部屋が静かすぎて、少し落ち着かなかった。
音楽を聞きすぎて、寝る時間が遅くなった。
でも、朝の空はきれいすぎると思った。

昨天熱過頭。到了晚上，房間仍安靜得讓人有點不自在。因為聽太多音樂，睡覺時間變晚了。不過，我覺得早晨的天空美得不可思議。

這段把過度程度、原因結果、ナ形容詞與「と思った」前的普通形放進同一條時間線。

第十四段｜生成任務
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

請完成四句原創輸出。

第一句，用い形容詞加すぎる。
例如天氣、價格、距離或聲音。

第二句，用ナ形容詞加すぎる。
例如安靜、簡單、漂亮或喜歡。

第三句，用動詞加すぎる。
例如看、聽、吃、喝或想。

第四句，把其中一句改成「～すぎて」，再接一個結果。

句型骨架：

＿＿すぎる。
＿＿すぎて、＿＿。

請暫停三十秒。
請使用自己的生活情境，不要只照念例句。

加碼任務。

用「とても」和「～すぎる」描述同一件事，讓兩句的評價差異清楚可聽見。

請暫停十五秒。

第十六段｜Exit Retrieval
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

い形容詞怎麼接すぎる？
請暫停四秒。
答案：去掉最後的い，再接すぎる。

ナ形容詞怎麼接？
請暫停四秒。
答案：直接接すぎる，不加な。

動詞怎麼接？
請暫停四秒。
答案：使用ます形去掉ます的語幹，再接すぎる。

「太好」？
請暫停四秒。
答案：よすぎる。

「說太多」？
請暫停四秒。
答案：言いすぎる。

「看太多了」？
請暫停五秒。
答案：見すぎた。

「太安靜而有點可怕」？
請暫停六秒。

請暫停六秒。

L15 課末速查
＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝＝

い形容詞：

強い → 強すぎる。
長い → 長すぎる。
暑い → 暑すぎる。
高い → 高すぎる。

特殊詞：

いい → よすぎる。
言う → 言いすぎる。
兩者不要混淆。
