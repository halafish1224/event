# AIMYON研究所｜《朝が嫌い》手機教材

這是一套完全獨立的純靜態教材，不依賴原本的 Next.js 專案，也不修改既有《マリーゴールド》與《君はロックを聴かない》手機教材。

## 開啟方式

直接雙擊 `index.html`，或把整個資料夾原樣上傳至任何靜態網站空間。四個檔案必須放在同一層：

- `index.html`
- `styles.css`
- `app.js`
- `README.md`

## 教材內容

- 14 天課程，另含 D0 起點診斷
- 附件字詞依「夜與朝、家與物件、關係與感受、動作與狀態、語氣與判斷」重新分群
- 六題一回合的主動提取卡，揭示後立即回饋
- 字詞搜尋與主題篩選
- 易混淆詞對比、語法詞塊、跨情境活用題
- 睡前 3 詞／醒後 1 分鐘再測的記憶交接紀錄
- 進度只使用瀏覽器 `localStorage`，不會上傳個人資料

## 著作權與使用範圍

教材只整理使用者附件中可見的字詞、必要短語與語法功能。完整例句均為教學用途重新撰寫，不收錄或依照原順序重製完整歌詞。

## 手機與電子閱讀器

版面支援 320px 起的小螢幕、瀏海安全區、44px 以上主要觸控目標與減少動態效果偏好。Kobo 等電子紙裝置若不完整支援 JavaScript，仍可閱讀字詞、語法與課表；互動進度建議使用手機瀏覽器。
