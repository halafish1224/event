# AIMYON研究所｜マリーゴールド 14天詞彙實驗課

這是一套獨立建立的手機版靜態教材，沒有修改 `aimyon-japanese` 既有網站、資料與 EPUB。

## 開啟方式

直接開啟 `index.html` 即可使用；不需要安裝套件或啟動伺服器。學習進度只保存在目前瀏覽器的 `localStorage`，不會上傳任何資料。

## 教材範圍

- 從使用者提供的《マリーゴールド》截圖提取字詞與短語。
- 依心與情緒、觀看與印象、動作與關係、景物與時間、程度與語氣重新分群。
- 所有完整教學例句均為重新撰寫，不收錄、重製或照原順序呈現完整歌詞。
- 14 天安排包含預測、立即回饋、間隔提取、相近詞對比、變化線索與跨情境產出。

## 研究轉譯原則

1. 先嘗試提取，再揭示答案與短回饋。
2. 以 0／1／3／7／14 日作為可執行的初始複習節奏，再依回想結果調整。
3. 同一字詞用日文、中文、相近詞與新情境反覆提取。
4. 每張手機卡只要求一個主要判斷，降低工作記憶負擔。
5. 歌曲提供情境與動機，但不能取代檢索、回饋與跨情境使用。

研究連結已收錄在網頁最下方的「查看研究依據與教材轉譯方式」。
