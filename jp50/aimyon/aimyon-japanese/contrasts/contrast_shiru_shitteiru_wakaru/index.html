知る／知っている／分かる

是取得新資訊、已處於知道狀態，還是理解內容？

information_acquisitionresult_stateunderstanding

語境決策規則

第一次得知資訊

選 知る

知る 是取得知識的變化。

已經知道

選 知る

知っている 表示取得後持續的狀態。

理解意思、理由或方法

選 分かる

分かる 聚焦理解。

最小對比

情境：剛得知名字／本來就知道名字／理解原因

名前を知った。／名前を知っている。

理由が分かった。

取得、持有知識與理解是三個不同階段。

常見錯誤

  • • 用 知る 回答『你知道嗎』的現在狀態。
  • • 把 分かる 的理解對象一律標成 を。

MEMORY HOOK

知る是把資訊拿進來；知っている是手上已經有；分かる是看懂它。
