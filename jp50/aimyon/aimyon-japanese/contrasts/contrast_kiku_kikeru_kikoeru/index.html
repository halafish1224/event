聞く／聴く／聞ける／聞こえる

是一般主動聽／詢問、專心欣賞、具備能聽的條件，還是聲音自然傳進耳中？

agencyfocused_listeningability_or_conditionaudibility

語境決策規則

主體主動去聽或詢問

選 聞く

聞く 表示主動行為。

專心欣賞音樂或留意聲音內容

選 聴く

聴く 凸顯專注聆聽。

設備、時間或能力允許聽

選 聞く

聞ける 是 聞く 的可能形。

聲音自然傳入耳中

選 聞こえる

聞こえる 表示自然聽得到。

最小對比

情境：主動播放並聽音樂／隔壁的音樂自然傳來

音楽を聞く。

隣から音楽が聞こえる。

左句主動聽；右句是自然可聽見。

情境：有耳機所以能聽／現在自然聽得到

イヤホンがあれば聞ける。

今はよく聞こえる。

聞ける 有條件；聞こえる 描述聲音可聽見的狀態。

情境：一般聽說明／專心欣賞音樂

説明を聞く。

音楽を聴く。

聴く 以字形凸顯專注欣賞；一般聽取與詢問多用 聞く。

常見錯誤

  • • 把自然聽見誤用 聞ける。
  • • 忽略 聞く 也可表示詢問。
  • • 把 聴く 當成所有聽覺情境的固定寫法。

MEMORY HOOK

一般去聽是 聞く；專心欣賞是 聴く；有條件能聽是 聞ける；聲音自己來是 聞こえる。
