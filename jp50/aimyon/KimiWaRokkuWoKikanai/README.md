# AIMYON研究所｜君はロックを聴かない・聲音與距離實驗課

這是獨立建立的手機版靜態教材，沒有修改以下既有內容：

- `aimyon-japanese` 原網站與 EPUB
- `AIMYON-Marigold-Mobile-Lab` 教材
- 使用者提供的原始截圖

## 使用方式

直接開啟 `index.html` 即可，不需要安裝套件或啟動伺服器。學習進度只會記錄在目前瀏覽器的 `localStorage`，不會傳送到外部。

## 教材內容

- 由附件提取詞彙、詞塊及語法觀察點。
- 重新分成聲音與唱片、動作與變化、距離與情緒、身體與視線、語氣與程度。
- 正式課程前診斷，加上 14 天短時課程。
- 包含提取卡、字詞搜尋、相近詞對比、句型替換及跨情境產出題。
- 所有完整教學例句均為重新撰寫；不收錄或按原順序重製完整歌詞。

## 學習設計

1. 答案顯示前先回想 5–8 秒。
2. 同一詞交替使用日文、中文、相近詞與新情境提問。
3. 朗讀後必須回答意思或完成情境題，避免只留下聲音熟悉感。
4. 以 0／1／3／7／14 日作為初始複習節奏，再依自評調整。
5. 每次只做 6 題，完成後離開螢幕口頭回想三個詞。

研究來源與教材轉譯說明已放在網頁下方「研究依據與教材轉譯」區塊。
