# ひかりもの：獨立歌曲教材

使用者原文8段完整保留；`content.mjs` 為唯一教材資料源。`node jp50/aimyon/hikarimono/build.mjs` 產生可供 GitHub Pages 直接閱讀的 index.html，建置時驗證原文與假名。

沿用 ring-ding 與 rhythm64 的現有樣式／互動腳本，不修改原檔。本頁新配色為橙褐色，無底部固定列，有 noindex（不是隱私保護）。

系統整合：songs/data.json 新增第10首；learning-map 加入本曲語法定位與兩個新概念，既有概念 ID／localStorage key 保持不變。進度僅存於地圖，歌曲練習欄不儲存。

教學重點：てきた／てくる、假設＋可能過去、ば條件、否定意願、ずに、樣態そう、詩意省略。避免將詩意內容視為心理診斷或強迫正向的規範。
