う、つ、る ➔ って

く ➔ いて / ぐ ➔ いで

❶ 第一類動詞（五段動詞）4 大圖像陣營與極大化例字
促音組 う・つ・る
う / つ / る ➔ って
🐢 鹿
「烏（う）龜（つ）鹿（る）」跳起來！
（變成小促音 っ 加上 て）
  • 買かう (購買)買かって
  • 洗あらう (洗滌)洗あらって
  • 待まつ (等待)待まって
  • 立たつ (站立)立たって
  • 取とる (拿取)取とって
  • 作つくる (製作)作つくって
  • 抱だく (擁抱)抱だいて (く組)
  • 乘のる (搭乘)乘のって
撥音濁音組 む・ぶ・ぬ
む / ぶ / ぬ ➔ んで
🪵 👃
「木（む）棒（ぶ）奴（ぬ）」帶鼻音！
（帶鼻音 ん，注意帶兩點 んで）
  • 讀よむ (閱讀)讀よんで
  • 飲のむ (飲用)飲のんで
  • 休やすむ (休息)休やすんで
  • 遊あそぶ (遊玩)遊あそんで
  • 選えらぶ (選擇)選えらんで
  • 飛とぶ (飛行)飛とんで
  • 死しぬ (死亡)死しんで
イ音便組 く・ぐ
く / ぐ ➔ いて / いで
😭 🦴
「哭（く）了去（いて），骨（ぐ）折加點（いで）」
（く 變 いて / ぐ 變 いで）
  • 書かく (書寫)書かいて
  • 聞きく (聆聽)聞きいて
  • 步あるく (步行)步あるいて
  • 開ひらく (打開)開ひらいて
  • 泳およぐ (游泳)泳およいで
  • 脱ぬぐ (脫下)脱ぬいで
  • 急いそぐ (趕快)急いそいで
す 變身組 す
す ➔ して
🗣️ 🪄
「Su（す）直接變身 Shi-te（して）」
（最直覺，順著發音變）
  • 話はなす (交談)話はなして
  • 出だす (拿出)出だして
  • 探さがす (尋找)探さがして
  • 押おす (按壓)押おして
  • 消けす (熄滅/關閉)消けして
  • 落おとす (弄丟/掉落)落おとして
⚠️ 兩大五段動詞「陷阱考點」特別收錄 絕對必考
🏃‍♂️💨
【特例 1】行いく 跑太快！
字尾是 く，但絕不變 いいて，而是促音：
行いって
🎭 👺
【特例 2】偽裝成一段的五段動詞
外表像一段（i/e段+る），骨子裡卻是五段！
依然遵守「促音組 (る➔って)」規則：
  • 帰かえる (回家)帰かえって
  • 走はしる (跑步)走はしって
  • 知しる (知道)知しって
  • 入はいる (進入)入はいって
  • 切きる (剪切)切きって
❷ 第二類（一段動詞）與第三類（不規則動詞）例字圖鑑
第二類動詞（一段動詞） 去 る + て
✂️ 🗑️
「剪掉尾巴 る，直接補上 て」
  • 食たべる (享用)食たべて
  • 見みる (觀看)見みて
  • 起おきる (起床)起おきて
  • 寢ねる (就寢)寢ねて
  • 忘わすれる (遺忘)忘わすれて
  • 教おしえる (教學)教おしえて
  • 開あける (開啟)開あけて
  • 閉しめる (關閉)閉しめて
第三類動詞（不規則動詞） 死記對照
⚡ 👑
「兩大原動核心與動作名詞組合」
  • する (做)して
  • 来くる (前來)来きて
  • 勉べん強きょうする (讀書)勉べん強きょうして
  • 散さん歩ぽする (散步)散さん歩ぽして
  • 旅りょ行こうする (旅行)旅りょ行こうして
  • キスする (親吻)キスして
