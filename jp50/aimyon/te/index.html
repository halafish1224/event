日文動詞「て形」視覺圖像記憶卡

透過「口訣 + 圖像聯想 + 色彩分組」輕鬆掌握日語動詞變化

🎵 經典口訣歌（可套用《小星星》旋律）

う、つ、る ➔ って
む、ぶ、ぬ ➔ んで
く ➔ いて / ぐ ➔ いで
す ➔ して
❶ 第一類動詞（五段動詞）4 大圖像陣營
促音組 う・つ・る
う / つ / る ➔ って
🐢 🦌
「烏（う）龜（つ）鹿（る）」跳起來！
（變成小促音 っ 加上 て）
  • 買う（買）➔ 買って
  • 待つ（等待）➔ 待って
  • 取る（拿取）➔ 取って
撥音濁音組 む・ぶ・ぬ
む / ぶ / ぬ ➔ んで
🪵 👃
「木（む）棒（ぶ）奴（ぬ）」帶鼻音！
（帶鼻音 ん，注意帶兩點 んで）
  • 讀む（閱讀）➔ 讀んで
  • 遊ぶ（遊玩）➔ 遊んで
  • 死ぬ（死亡）➔ 死んで
イ音便組 く・ぐ
く / ぐ ➔ いて / いで
😭 🦴
「哭（く）了去（いて），骨（ぐ）折加點（いで）」
（く 變 いて / ぐ 變 いで）
  • 書く（寫）➔ 書いて
  • 泳ぐ（游泳）➔ 泳いで
す 變身組 す
す ➔ して
🗣️ 🪄
「Su（す）直接變身 Shi-te（して）」
（最直覺，順著發音變）
  • 話す（交談）➔ 話して
  • 發す（發射）➔ 發して
⚠️ 超級特例陷阱卡 唯一特例
行く（いく） ➔ 行くだ ❌ 行って ⭕
🏃‍♂️💨
「去（行く）跑得太快，變成促音！」
（不走 イ音便，強制變小促音 って）
  • 行く（去）➔ 行って
❷ 第二類（一段）與第三類（不規則）動詞
第二類動詞（一段動詞） 去 る + て
✂️ 🗑️
「剪掉尾巴 る，直接補上 て」
  • 食べる（吃）➔ 食べて
  • 見る（看）➔ 見て
  • 忘れる（忘記）➔ 忘れて
第三類動詞（不規則動詞） 死記對照
⚡ 👑
「兩大魔王，直接背熟」
  • する（做）➔ して
  • 来（く）る（來）➔ 来（き）て
