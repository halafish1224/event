STEP 01 — 找原形

原形＝辭書形

查辭典通常查「食べる」，不是「食べました」。本頁每個詞條都能以漢字、假名、中文意思，或已收錄的變化形反查。

STEP 02 — 對照句尾

形式、時態、語體分開看

食べた是た形，也是普通體的過去肯定；食べました是禮貌體的過去肯定。兩者禮貌程度不同，並非不同時間。

本頁的「每句解析」以該詞條的目標動詞為主。粗體與底線標出例句中的目標動詞，下方列出原形與當前形式。て形例句若接いる或其他述語，整句時間由後方述語與上下文共同決定。
02 / 時態地圖

四格時態 × 兩種語體

「非過去」包含習慣、一般情況、現在狀態或未來；動作動詞的原形通常不單獨表示「此刻正在做」。以下先以獨立句句尾為範圍，嵌入子句時還要考慮主句時間。

以食べる（吃）為共同詞條
時間／肯否普通體禮貌體理解方式
非過去肯定食べる食べます吃／會吃；需看情境
過去肯定食べた食べました吃了／曾吃
非過去否定食べない食べません不吃
過去否定食べなかった食べませんでした沒吃

另一種常見禮貌否定是「食べないです／食べなかったです」；本頁以「ません／ませんでした」作為主要對照。た形也可在句型中表示完成等意義，不宜把所有た都機械翻成「昨天」。

て形是接續入口

食べて ＋ いる → 食べている
食べて ＋ ください → 食べてください

食べて本身不是「現在式」。前者可表示正在吃，後者是請對方吃。句型改變，功能就改變。

同一個動作，不同時間框架

毎日、朝ご飯を食べる。
每天吃早餐：習慣，原形。
今、朝ご飯を食べている。
現在正在吃早餐：食べる→食べて＋いる。
明日、朝ご飯を食べる。
明天吃早餐：未來，仍可用原形。

03 / 變化規則

先分類，再走兩條變化路線

第一類：五段動詞

以字尾所在的音段變化。ない形走あ段，ます形走い段；て形與た形另記音便。

不能只看「る」判斷。帰る、走る、知る、入る都是五段。像切る、要る也屬五段，遇到不確定的詞要查詞性。

第二類與第三類

第二類（一段）：食べる→食べ＋て／た／ない／ます。通常以い段或え段＋る結尾，但這只能當線索。

第三類（不規則）：する與来る。勉強する沿用する；できる則按一段變化。

五十音與音便：最後一個假名如何變
原形尾音ない形字尾ます形字尾て形 → た形例詞
うわないいますって → った買う
つたないちますって → った待つ
るらないりますって → った帰る
むまないみますんで → んだ読む
ぶばないびますんで → んだ遊ぶ
ぬなないにますんで → んだ死ぬ
くかないきますいて → いた書く
ぐがないぎますいで → いだ泳ぐ
すさないしますして → した話す
三個重點例外：行く→行って／行った；ある→ない／なかった；う結尾的否定用わない，例如買わない。表內「あ段」不能直接套成「あない」。

保留原稿的四組記憶法，補上た形

促音組：う・つ・る → って → った
撥音組：む・ぶ・ぬ → んで → んだ
イ音便組：く → いて → いた；ぐ → いで → いだ
す組：す → して → した

可依原稿方式套入熟悉的旋律反覆念；中文諧音只作記憶提示，日語讀音仍以假名為準。「る→って」只適用五段，不能套到食べる。

読む（原形）→読まない（非過去否定）→読まなかった（過去否定）

過去否定的核心：先正確得到ない形，再把最後的ない換成なかった。不是在原形後直接加なかった，也不是在読まない後追加た。

這裡從詞條往外延伸。所有例句都標出接續的原形與變化；需要重新比較四時態，可點回相關詞條。

て形＋いる

本を読んでいる。

正在讀書。

解析：読む → 読んで＋いる；整體是非過去肯定。

現在正在進行的動作。過去進行用読んでいた，否定読んでいない，過去否定読んでいなかった。

詞條全形對照：読む

て形＋いる：結果狀態

その事実を知っている。

知道那件事。

解析：知る → 知って＋いる；得知後的狀態。

四格比較：知っている／知っていた／知らない／知らなかった。一般「不知道」通常用知らない；知っていない在特定對比等語境也會出現。

詞條全形對照：知る

て形＋ください

ここで待ってください。

請在這裡等。

解析：待つ → 待って＋ください；請求。

不是「等待的現在式」。否定請求用待たないでください，不是把待って直接加ない。

詞條全形對照：待つ

ない形＋でください

約束を忘れないでください。

請不要忘記約定。

解析：忘れる → 忘れない＋でください；否定請求。

ないで常表示不做某事；なくて可表示否定接續、原因等，不能在所有句型中互換。

詞條全形對照：忘れる

て形＋もいい

ここに入ってもいいです。

可以進這裡。

解析：入る → 入って＋もいいです；許可。

此句表達被允許。若想表達能力「能進去」，通常另用可能形入れる；許可與能力不是同一件事。

詞條全形對照：入る

た形＋ことがある

日本に行ったことがある。

曾經去過日本。

解析：行く → 行った＋ことがある；經驗。

ある是本句非過去肯定的述語。沒去過可說行ったことがない；不要只因行った就判定整句是過去肯定。

詞條全形對照：行く

原形＋前に／た形＋後で

食べる前に。／食べた後で。

吃之前。／吃之後。

解析：食べる接前に；食べた接後で。此處為片語，需接上下文。

未來的行程也可用食べた後で；た在此標示相對於後續事情已完成，不能只理解為曆法上的過去。

詞條全形對照：食べる

ない形去ない＋なければならない

日本語を勉強しなければならない。

必須學日文。

解析：勉強する → 勉強しない → 勉強しなければ＋ならない；義務。

雖然構造包含否定，整句意思是「必須做」。學習時要同時查形式與整個句型的功能。

詞條全形對照：勉強する

06 / 觀念校正

把最容易混淆的關係分清楚

不做 ≠ 不能做

泳がない：不游泳。
泳げない：不能游泳。

前者是泳ぐ的ない形；後者是可能形泳げる的否定。詞條列出的ない形不能一概翻成「不能」。

動詞後不直接加です

初學者想把食べる改禮貌，請用食べます。不要直接拼成「食べるです」。食べるんです是另一個帶說明語氣的構造。

ている並非都在「正在」

読んでいる常指正在讀；死んでいる指已死亡；知っている指知道。分辨動作進行、結果狀態與反覆習慣，要看動詞意思和上下文。

否定不是刪掉た就好

読んだ的否定是読まなかった。先回到読む，再走「読まない→読まなかった」。過去肯定與過去否定走不同的變化路線。

閱讀順序建議：先記原形與分類 → 念出て形、た形 → 推導ない形、なかった形 → 比較ます四格 → 遮住振假名與答案自測。一次練 4～6 個詞，隔天用完整句子回想。
07 / 主動回想

先想答案，再打開解析

保留原稿六題的考點，擴充為十二題。可用滑鼠、觸控，或鍵盤 Tab 移到題目後按 Enter／空白鍵展開。

買う → て形？

買って

五段う→って。

回查：買う

聞く → 過去否定？

聞かなかった

聞く→聞かない→聞かなかった。

回查：聞く

帰る → て形？

帰って

帰る是五段，不能只因え段＋る就當一段。

回查：帰る

思う → 過去肯定？

思った

う→って→った。

回查：思う

来る → 非過去否定？讀音？

来ない（こない）

来る的不規則讀音：く／き／こ。

回查：来る

できる → 過去否定？

できなかった

按一段：できる→できない→できなかった。

回查：できる

ある → 普通體非過去否定？

ない

不是あらない；禮貌體則是ありません。

回查：ある

行く → た形？

行った

て形・た形特例；不是行いた。

回查：行く

食べる → 禮貌體過去否定？

食べませんでした

普通體則是食べなかった。

回查：食べる

「知道」通常用知る還是知っている？

知っている

得知後仍持有資訊的狀態；不知道常用知らない。

回查：知る

読む → て形，再變過去進行？

読んで → 読んでいた

て形本身沒有時態；いる→いた才標示過去。

回查：読む

出す與出る的て形？

出して／出て

出す是五段；出る是一段，分類不同。

回查：出る
