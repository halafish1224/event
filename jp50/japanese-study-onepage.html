02｜50 音 ×「5 段 10 行」

用座標理解假名：行＝同一子音系列；段＝同一母音系列。

五段：あ段・い段・う段・え段・お段
十行：あ行・か行・さ行・た行・な行・は行・ま行・や行・ら行・わ行
行＼段あ段い段う段え段お段
あ行あaいiうuえeおo
か行かkaきkiくkuけkeこko
さ行さsaしshiすsuせseそso
た行たtaちchiつtsuてteとto
な行なnaにniぬnuねneのno
は行はhaひhiふfuへheほho
ま行まmaみmiむmuめmeもmo
や行やya—ゆyu—よyo
ら行らraりriるruれreろro
わ行わwa———をo
特殊んn／自己也佔 1 mora

母音

あ・い・う・え・お

日文核心母音是 a / i / u / e / o。例：か = k + a。

子音

例如 k / s / t / n / h / m / r。同一「行」通常共享近似子音骨架。

例：か・き・く・け・こ ≈ k + a/i/u/e/o。

易混淆假名速查
ぬ / ね / めれ / わる / ろ は / ほさ / ち

03｜濁音・半濁音・促音・拗音・長音

這一區是「讀得出來」和「聽得懂」的核心。

濁音 ゛

か→が　さ→ざ　た→だ　は→ば

主要改變子音；母音通常保持不變。

半濁音 ゜

は→ば→ぱ

は行加半濁點形成 ぱ・ぴ・ぷ・ぺ・ぽ。

促音「っ」vs 長音

項目核心是否有母音是否佔一拍例子
促音 っ後續子音「卡住／延長」沒有自己的母音是きって = き・っ・て
長音前一個母音延長延續前一母音是こう = こ・う
記法：促音＝卡一拍；長音＝拉一拍。
がっこう 同時有促音與長音：が｜っ｜こ｜う＝4 mora。

拗音「ゃ・ゅ・ょ」

きゃ
kya・1 拍
しゅ
shu・1 拍
ちょ
cho・1 拍
りょ
ryo・1 拍

きや＝2 拍；きゃ＝1 拍。看到小字不代表促音，只有小 っ 才是促音。

04｜助詞核心：の・は・が・を・と

拆歌詞時，助詞就是句子的路標。

の

名詞與名詞的關聯

夜の空

夜晚的天空

は

設定主題，助詞時念 wa

私は…

至於我……

が

指出主體／焦點

花が咲く

花開了

を

標記動作直接作用的對象，通常念 o

花を見る

看花

と

引用／把前面內容打包

いいと思う

我覺得很好

拆句流程：先找句尾動詞 → 找助詞 → 找主體／對象 → 判斷省略 → 最後才翻中文。

05｜動詞與 SOV 語序

日文常把動詞放在句尾，因此先看句尾，是拆長句的高效率方法。

S → O → V　／　主語・主題 → 對象 → 動詞

花を見る。

花＝花／を＝動作對象／見る＝看

自然中文：看花。

花が咲く。

花＝花／が＝主體／咲く＝開花

自然中文：花開了。

目前核心動詞

辭書形讀音意思提示
見るみる看一段動詞
聞くきく聽／問依助詞與語境判斷
思うおもう想／覺得～と思う
咲くさく開花花が咲く
なるなる變成優しくなる
できるできる能做到できない＝做不到

06｜い形容詞 vs な形容詞

い形容詞

優しい → 優しくなる

修飾名詞可直接放前面：優しい人。

接 なる 時：い → く。

な形容詞

静か → 静かになる

修飾名詞：静かな夜。

接 なる 時：＋に。

陷阱：きれい 雖然字面最後有「い」，但屬於な形容詞。例：きれいな花。

否定

類型基本形否定意思
い形容詞優しい優しくない不溫柔
な形容詞静か静かじゃない不安靜

07｜五段動詞的「ない形」

這是目前最需要精準掌握的規則之一。

五段動詞：辭書形最後的「う段假名」→ 保持同一行 → 移到「あ段假名」→ 加 ない。
特例：う → わ。
語尾同一行的あ段例字ない形
うわ買う買わない
くか書く書かない
ぐが泳ぐ泳がない
すさ話す話さない
つた待つ待たない
ぬな死ぬ死なない
ぶば遊ぶ遊ばない
むま読む読まない
るら取る取らない

為什麼叫「五段動詞」？

書かない → 書きます → 書く → 書ける → 書こう

同一個語尾會跨過 あ・い・う・え・お 五段變化，因此稱「五段動詞」。

不能套用到一段動詞：
見る → 見ない
食べる → 食べない
不規則：
する → しない
来る（くる）→ 来ない（こない）
ある → ない
逆推原形技巧

看到 聞かない：先切 聞か＋ない → 「か」是か行・あ段 → 同一行的う段是「く」→ 原形 聞く。

08｜Aimyon《愛の花》短句拆解

只使用目前已在課程中指定學習的短句，不收錄完整歌詞。

心は優しくなれたかな

心（こころ）

內心、心境。

は

主題助詞，念 wa。「至於這顆心……」

優しく

優しい 的連用形：い→く。

なれた

なる→なれる→なれた：能夠變成了。

かな

自問、自我反思語氣：「不知道是不是呢……」

變形鏈： 優しい → 優しく → 優しくなる → 優しくなれる → 優しくなれた
自然理解：「不知道我的心，是不是已經變得更溫柔了呢？」
重點不是硬翻每一個字，而是看「心は」設定主題、「優しく」指出狀態、「なれた」帶可能／達成感、「かな」形成自問。

Aimyon 歌詞拆解固定流程

  1. 先讀假名與切 mora。
  2. 先找句尾：動詞／形容詞／語氣詞。
  3. 標出助詞：は・が・を・の・と。
  4. 找主體與動作對象。
  5. 判斷省略的「我／你／它」。
  6. 把變形還原成基本形。
  7. 先直譯日文骨架，再做自然中文。
