01 · Big Picture

先理解：日文為什麼一直「變形」？

因為日文會把「肯定、否定、時間、接續方式」 直接表現在述語的形式上。 所以學習重點不是背很多獨立單字， 而是辨認： 現在是哪一類詞？它的哪個部分需要改變？

最重要的觀念： 「變化」不是製造新的單字， 而是同一個詞依照句子的功能， 換成不同形式。
日文述語系統 一句話最後負責描述「做什麼、怎麼樣、是什麼」的部分。
動詞 食べる、行く、読む、見る……
→ 有完整的動詞活用。
い形容詞 高い、暑い、おいしい……
→ 主要改變最後的「い」。
ナ形容詞＋名詞 好きだ、静かだ、学生だ……
→ 兩者的句尾變化高度相似。

03 · Pattern Recognition

先不要背五欄，先看四種「變化邏輯」

動詞
食べる

動詞本身具有完整活用系統。 不同動詞類別又會影響 ない形、た形、て形的形成方式。

核心：辨認動詞類型
い形容詞
高い

最重要的變化位置通常就是最後的 い。

核心：改「い」
ナ形容詞
好きだ

「好き」本體不變， 主要透過句尾的 だ系統 表示肯定、否定與過去。

核心：看「だ」
名詞
学生だ

名詞述語與ナ形容詞的句尾變化 非常接近。

核心：與ナ形容詞一起記
04 · Verb

動詞：食べる

食べる（たべる）＝吃。 這裡先使用規則最清楚的一段動詞作為基準。

現在肯定
食べる
現在否定
食べない
過去肯定
食べた
過去否定
食べなかった
接續
食べて……
理解重點： 食べて 通常具有「還沒說完」的感覺。 後面可以繼續接： 食べている、 食べてください、 食べてみる 等文法。
05 · I-Adjective

い形容詞：高い

高い（たかい）＝高的／貴的。 い形容詞本身具有活用能力， 所以不需要依靠「だ」來完成基本普通形。

核心規則

原形
高い
否定
高い → 高くない
過去
高い → 高かった
過去否定
高くなかった
接續
高くて

你真正要記的是

不是五個完整單字， 而是最後的 「い」可以切換成不同形式。

い
→ くない
い
→ かった
い
→ くて
例： この店は安くて、おいしいです。
這間店便宜，而且很好吃。
06 · Na-Adjective

ナ形容詞：好き

這正好可以回答一個重要問題： 為什麼是 好き， 卻沒有 好きい？

句尾
好きだ

「好き」本身不需要增加「い」。 普通形句尾使用「だ」。

修飾名詞
好きな人

修飾後面的名詞時， 使用「な」連接。 這也是「ナ形容詞」名稱的來源。

現在肯定
好きだ
現在否定
好きじゃない
過去肯定
好きだった
過去否定
好きじゃなかった
接續
好きで
○ 正確
好きだ
好きな人
好きだった
× 錯誤
好きい
好きかった
07 · Noun

名詞：学生

名詞本身不活用， 但當它成為句子的述語時， 後面的「だ」系統會發生變化。

現在肯定
学生だ
現在否定
学生じゃない
過去肯定
学生だった
過去否定
学生じゃなかった
接續
学生で
學習捷徑： ナ形容詞與名詞可以先視為同一家族。
好きだ → 好きだった → 好きで
学生だ → 学生だった → 学生で
08 · Same Family

ナ形容詞＋名詞，為什麼可以一起記？

功能 ナ形容詞 名詞
現在肯定 好きだ 学生だ
否定 好きじゃない 学生じゃない
過去 好きだった 学生だった
過去否定 好きじゃなかった 学生じゃなかった
接續 好きで 学生で
09 · Connection Form

「て形」的真正概念： 其實是「接續」

初學教材常把這整組概念統稱為「て形」， 但嚴格來看，不同詞類的接續形式並不完全相同。

動詞
食べて

真正的動詞て形。

い形容詞
高くて

い → くて。

ナ形容詞
好きで

使用「で」連接。

名詞
学生で

同樣使用「で」。

所以最好的理解不是：
「所有東西都變成て形」

而是： 「每一類詞都有自己的『接續模式』， 用來告訴聽者：我的話還沒結束。」
10 · Examples

四種接續，一起比較

動詞

ご飯を食べて、寝ます。

吃飯，然後睡覺。

食べる → 食べて

い形容詞

この店は安くて、おいしいです。

這間店便宜，而且好吃。

安い → 安くて

ナ形容詞

この町は静かで、きれいです。

這個城鎮安靜又漂亮。

静かだ → 静かで

名詞

兄は学生で、私は会社員です。

哥哥是學生，而我是上班族。

学生だ → 学生で

11 · Verb Te-Form

動詞的て形怎麼形成？

一段動詞最單純； 五段動詞則依照最後一個假名產生不同音便。

一段動詞

基本規則： る → て

食べる → 食べて
見る → 見て
起きる → 起きて
寝る → 寝て

五段動詞

う・つ・る → って
買う → 買って
待つ → 待って
帰る → 帰って
む・ぶ・ぬ → んで
読む → 読んで
遊ぶ → 遊んで
死ぬ → 死んで
く → いて
書く → 書いて
ぐ → いで
泳ぐ → 泳いで
す → して
話す → 話して
特別 行く
行く → 行って

雖然以「く」結尾， 但不是「行いて」。

12 · Why Te-Form Matters

為什麼て形這麼重要？

因為て形不是只代表一個意思， 而是一個可以接上大量文法的 「連接平台」。

結構 例子 主要概念 中文理解
Vて、V 食べて寝る 動作連接 吃了然後睡
Vている 食べている 處於某動作／狀態 正在吃
Vてください 見てください 請求 請看
Vてもいい 食べてもいい 許可 可以吃
Vてはいけない 入ってはいけない 禁止 不可以進去
Vてみる 食べてみる 嘗試 吃吃看
Vておく 予約しておく 預先準備 先預約好
Vてしまう 忘れてしまった 完成／遺憾 不小心忘了
13 · Hidden Pattern

另一個值得看懂的共同規則： ない → なかった

觀察：

動詞
食べない → 食べなかった
い形容詞
高くない → 高くなかった
ナ形容詞
好きじゃない → 好きじゃなかった
名詞
学生じゃない → 学生じゃなかった
所以不要把「なかった」當成四套規則。
先建立： ない → なかった 的共同概念，就能大幅降低記憶量。
14 · Plain vs Polite

普通形與禮貌形不要混在一起

詞類 普通形 禮貌形
動詞 食べる 食べます
い形容詞 高い 高いです
ナ形容詞 好きだ 好きです
名詞 学生だ 学生です
好きだ 的禮貌形是 好きです， 不是 好きだです 。
15 · Check Yourself

快速確認是否真的理解

先自己回答，再展開答案。

Q1｜高い 的過去形是？
高かった

い形容詞： い → かった。

Q2｜好き 的過去形是「好きかった」嗎？
不是。

好きだ → 好きだった

因為好き是ナ形容詞， 不走い形容詞的「かった」變化。

Q3｜学生 的接續形式是？
学生で

例如： 兄は学生で、私は会社員です。

Q4｜読む 的て形是？
読んで

五段動詞： む・ぶ・ぬ → んで。

FINAL MAP

最後只需要牢記四件事

① 動詞 有自己的活用系統。
食べる → 食べない → 食べた → 食べて
② い形容詞 主要改最後的「い」。
高い → 高くない → 高かった → 高くて
③ ナ形容詞 本體通常不動， 改「だ」系統。
好きだ → 好きじゃない → 好きだった → 好きで
④ 名詞 與ナ形容詞句尾變化高度相似。
学生だ → 学生じゃない → 学生だった → 学生で

最終學習公式：

動詞＝看活用
い形容詞＝看「い」
ナ形容詞＋名詞＝看「だ」
接續形＝「話還沒說完，後面要繼續接」
